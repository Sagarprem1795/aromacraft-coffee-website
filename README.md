## 📌 Project Overview & Structure

The website consists of **11 distinct pages** connected through a unified navigation bar and footer:

1. **`index.html`** – Homepage with hero banner, impact metrics, feature pillars, seasonal roasts, and customer reviews.
2. **`about.html`** – Brand origin, sourcing philosophy, and roastery principles.
3. **`menu.html`** – Café drink and bakery menu with categorized sections, tags, and customization pricing.
4. **`shop.html`** – Whole-bean retail product catalog with flavor notes and pricing.
5. **`product-detail.html`** – Deep dive into single-origin lot specifications (elevation, roast curve, grind selector).
6. **`brewing-guides.html`** – Hub index for manual brew tutorials.
7. **`guide-pour-over.html`** – Step-by-step V60 conical pour-over brewing instructions.
8. **`guide-french-press.html`** – Step-by-step immersion French press brewing guide.
9. **`sustainability.html`** – Direct-trade transparency ledger, agroforestry standards, and price comparison table.
10. **`locations.html`** – Roastery & espresso bar locations, opening hours, amenity tags, and interactive map embed.
11. **`blog.html`** – Roastery journal featuring articles on bean processing, water chemistry, and farm visits.
12. **`contact.html`** – Inquiry form for general queries, wholesale supply, and barista workshops.

## 🛠️ Built With

- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<form>`, `<table>`, `<footer>`)
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, media queries, and pure CSS `@keyframes` animations
- **No JavaScript:** Completely functional with zero script dependencies to satisfy all assignment criteria

---

## 🚀 Key Design & Technical Features

- **Micro-Interactions & Animations:** Pure CSS steam-floating animated vector SVG logo, smooth transitions, and hover card elevation.
- **Responsive Layouts:** Mobile-first approach scaling smoothly across phones, tablets, and desktop displays.
- **Embedded Map & Forms:** Zero-JS Google Maps embed and accessible HTML form fields with focus states.
- **Accessibility & Semantics:** Structured heading hierarchies (`h1`–`h4`), semantic container tags, and alt text for all images.
